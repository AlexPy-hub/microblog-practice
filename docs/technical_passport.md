# Технический паспорт проекта

## 1. Общая информация

**Название проекта:** Microblog Practice Project

**Тип проекта:** веб-приложение «Микроблог»

**Назначение:** учебное веб-приложение для регистрации пользователей, публикации записей и управления собственными публикациями.

## 2. Пользователь

Основным пользователем системы является зарегистрированный пользователь веб-приложения.

Пользователь может:

* зарегистрироваться;
* войти в аккаунт;
* выйти из аккаунта;
* просматривать публикации;
* создавать публикации;
* редактировать собственные публикации;
* удалять собственные публикации;
* просматривать профиль;
* загружать аватар.

## 4. Основные компоненты

### Flask Application

Основное приложение создаётся в:

`app/__init__.py`

Файл отвечает за создание Flask-приложения, подключение базы данных и регистрацию маршрутов.

### Authentication

Файл:

`app/auth.py`

Отвечает за:

* регистрацию;
* авторизацию;
* выход из аккаунта;
* проверку паролей;
* работу с пользовательской сессией.

### Database Models

Файл:

`app/models.py`

Содержит модели:

* `User`;
* `Post`.

### Web Routes

Файл:

`app/routes.py`

Содержит маршруты для:

* создания публикаций;
* редактирования;
* удаления;
* просмотра профилей;
* изменения аватара.

### REST API

Файл:

`app/api.py`

Реализует API для работы с публикациями.

### Templates

Каталог:

`app/templates/`

Содержит HTML-шаблоны интерфейса приложения.

### Static Files

Каталог:

`app/static/`

Содержит CSS, JavaScript и загружаемые изображения.

## 5. База данных

Используется SQLite.

Основные таблицы:

* `users`;
* `posts`.

Между таблицами существует связь один-ко-многим:

`User 1 : N Post`

Один пользователь может иметь несколько публикаций.

## 6. API

Реализованы следующие операции:

| Метод  | Endpoint          | Назначение                  |
| ------ | ----------------- | --------------------------- |
| GET    | `/api/posts`      | Получение списка публикаций |
| POST   | `/api/posts`      | Создание публикации         |
| GET    | `/api/posts/<id>` | Получение одной публикации  |
| PUT    | `/api/posts/<id>` | Изменение публикации        |
| DELETE | `/api/posts/<id>` | Удаление публикации         |

## 7. Тестирование

Для тестирования используется pytest.

Тестами проверяются:

* главная страница;
* регистрация;
* авторизация;
* создание публикации;
* редактирование публикации;
* удаление публикации;
* получение публикаций через API;
* создание публикации через API;
* получение одной публикации;
* обновление публикации;
* удаление публикации.

## 8. Запуск проекта

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Запуск:

```bash
python run.py
```

Адрес локального приложения:

```text
http://127.0.0.1:5000
```

Запуск тестов:

```bash
pytest
```
