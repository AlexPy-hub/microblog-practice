# Таблица трассируемости

Таблица связывает функциональные возможности проекта с файлами исходного кода и пользовательскими страницами, на которых эти функции могут быть проверены.

| Функция                   | Реализация                              | Файл / папка                                  | Страница / endpoint      |
| ------------------------- | --------------------------------------- | --------------------------------------------- | ------------------------ |
| Регистрация пользователя  | Создание аккаунта                       | `app/auth.py`                                 | `/register`              |
| Вход в аккаунт            | Авторизация и создание сессии           | `app/auth.py`                                 | `/login`                 |
| Выход из аккаунта         | Завершение сессии                       | `app/auth.py`                                 | `/logout`                |
| Просмотр публикаций       | Вывод списка постов                     | `app/__init__.py`, `app/templates/index.html` | `/`                      |
| Создание публикации       | Добавление поста в БД                   | `app/routes.py`                               | `/posts/create`          |
| Редактирование публикации | Изменение собственного поста            | `app/routes.py`                               | `/posts/<id>/edit`       |
| Удаление публикации       | Удаление собственного поста             | `app/routes.py`                               | `/posts/<id>/delete`     |
| Просмотр профиля          | Вывод профиля и публикаций пользователя | `app/routes.py`                               | `/profile/<username>`    |
| Загрузка аватара          | Сохранение изображения пользователя     | `app/routes.py`                               | `/profile/edit`          |
| Модель пользователя       | Таблица пользователей                   | `app/models.py`                               | База данных `users`      |
| Модель публикации         | Таблица публикаций                      | `app/models.py`                               | База данных `posts`      |
| REST API: список          | Получение публикаций                    | `app/api.py`                                  | `GET /api/posts`         |
| REST API: создание        | Создание публикации                     | `app/api.py`                                  | `POST /api/posts`        |
| REST API: получение       | Получение одной публикации              | `app/api.py`                                  | `GET /api/posts/<id>`    |
| REST API: изменение       | Изменение публикации                    | `app/api.py`                                  | `PUT /api/posts/<id>`    |
| REST API: удаление        | Удаление публикации                     | `app/api.py`                                  | `DELETE /api/posts/<id>` |
| Тестирование              | Автоматические тесты                    | `tests/test_app.py`                           | `pytest`                 |

## Проверка

Каждая основная функция проекта имеет соответствующую реализацию в исходном коде и пользовательский маршрут или API endpoint, через который её можно проверить.
