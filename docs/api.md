# API документация

## Назначение

REST API предназначен для получения, создания, изменения и удаления публикаций микроблога.

Базовый адрес:

```text
/api
```

---

## GET /api/posts

Получение списка всех публикаций.

### Ответ

HTTP `200 OK`

```json
[
  {
    "id": 1,
    "title": "Моя первая публикация",
    "content": "Текст публикации",
    "user_id": 1,
    "created_at": "2026-09-19T12:00:00"
  }
]
```

---

## POST /api/posts

Создание новой публикации.

### Тело запроса

```json
{
  "title": "Новая публикация",
  "content": "Текст новой публикации",
  "user_id": 1
}
```

### Успешный ответ

HTTP `201 Created`

Возвращается созданная публикация.

### Ошибка

HTTP `400 Bad Request`, если отсутствуют обязательные данные.

---

## GET /api/posts/<id>

Получение одной публикации по идентификатору.

### Пример

```text
GET /api/posts/1
```

### Успешный ответ

HTTP `200 OK`

Возвращается объект публикации.

### Ошибка

HTTP `404 Not Found`, если публикация не существует.

---

## PUT /api/posts/<id>

Изменение существующей публикации.

### Пример

```text
PUT /api/posts/1
```

### Тело запроса

```json
{
  "title": "Изменённый заголовок",
  "content": "Изменённый текст"
}
```

### Успешный ответ

HTTP `200 OK`

Возвращается обновлённая публикация.

### Ошибка

HTTP `404 Not Found`, если публикация не существует.

---

## DELETE /api/posts/<id>

Удаление публикации.

### Пример

```text
DELETE /api/posts/1
```

### Успешный ответ

HTTP `200 OK`

Возвращается сообщение об успешном удалении.

### Ошибка

HTTP `404 Not Found`, если публикация не существует.
